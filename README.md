# powerbi-business-dashboard
Power BI Business Performance Dashboard

This project showcases an interactive dashboard built using Power BI to analyze business performance using a retail dataset.

Key Features

Data cleaning and transformation using Power Query
Data modeling and DAX measures
Interactive dashboard with filters and KPIs

Dashboard Insights
Sales trends over time
Profit analysis by sub-category
Regional performance comparison

Tools Used
Power BI
Excel
DAX
